ml4seeding Documentation
=========================

``ml4seeding`` is a Python package for microsite classification from
high-resolution drone imagery to support precision aerial reforestation.

Statement of Need
-----------------

Drone-based aerial seeding requires precise identification of microsites where
seed germination and seedling establishment are most likely. Automated
microsite classification from drone imagery enables precision seed deployment.

Current Status
--------------

This is an early public-alpha release (0.1.0a1). The API is not yet stable.
